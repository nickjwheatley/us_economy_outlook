# Dashboard Spec

## Current MVP

The generated dashboard is `outputs/dashboard.html`.

It includes:

- Headline score
- Regime
- Recession-risk label
- Prototype recession probability
- Rules score and ML regime score
- SaaS revenue implication
- VTI market implication
- Market valuation block, including CAPE-style valuation gauges
- Block score table
- Indicator detail table
- Current value, Q/Q change, Y/Y change, and trajectory score for each indicator

## Next Dashboard Additions

- Recession shading
- Indicator selector with 20-year history chart for each score input
- Block heatmap
- Top positive and negative drivers
- Change since prior run
- Data freshness panel

- Valuation panel with CAPE, forward P/E, market-cap-to-GDP, and equity risk premium
