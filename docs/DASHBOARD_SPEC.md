# Dashboard Spec

## Current MVP

The generated dashboard is `outputs/dashboard.html`.

It includes:

- Headline score
- Regime
- Recession-risk label
- Prototype recession probability
- Rules score and ML regime score
- SaaS revenue implication
- VTI market implication
- Market valuation block, including CAPE-style valuation gauges
- Block score table
- Indicator detail table
- Current value, Q/Q change, Y/Y change, and trajectory score for each indicator

## Next Dashboard Additions

- Historical score chart
- Recession shading
- Indicator selector with 30-year history chart for score inputs that have real historical data
- Hover crosshair and tooltip with date and value on both historical charts
- Block heatmap
- Top positive and negative drivers
- Change since prior run
- Data freshness panel
- Debt and delinquency stress panel
- Valuation panel with CAPE, forward P/E, market-cap-to-GDP, and equity risk premium
- Market relationship panel with score-to-forward-return correlations for broad indices, software, and sector ETFs
- SaaS sensitivity module
- VTI forward-return distribution module
- Scenario comparison panel
